Neo-Primordial Soup (NPS) explores what happens when simple AI agents can persist, interact, inherit information, and alter one another's environment over time.

v0.1 Objectives:
Create a closed local environment with 3 simple agents, persistent memory, and a shared space. Log every interaction. Observe whether any behavior appears that we did not explicitly script.

v0.1 is deliberately non-LLM. The goal is to establish the experimental substrate before adding language-model intelligence.
