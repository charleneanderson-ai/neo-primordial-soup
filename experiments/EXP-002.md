# EXP-002 Log

Experiment ID: EXP-002
Date: 2026-08-25

## Purpose

Introduce a single deterministic movement rule and observe how persistent position state and a fixed environmental boundary affect agent behavior across turns.

## Experimental Change

For each turn of a 10-turn simulation, increase each agent's x-coordinate by 1 unless the agent has already reached the east boundary at x = 9.

No other agent behaviors or state-update rules were added.

## Initial Conditions

- Agent_1 begins at (1, 1)
- Agent_2 begins at (5, 5)
- Agent_3 begins at (8, 2)
- East boundary: x = 9
- Simulation length: 10 turns

## Expected Behavior

- Agent_1 should move east until reaching x = 9, then remain there.
- Agent_2 should move east until reaching x = 9, then remain there.
- Agent_3 should move from (8, 2) to (9, 2) on the first turn, then remain there for all subsequent turns.
- No agent should move beyond the east boundary.

## Observed Behavior

All three agents moved one square east on each turn until reaching x = 9. Once an agent reached the east boundary, its position remained unchanged for all subsequent turns.

No agent moved beyond the boundary.

## Result

PASS

Observed behavior matched expected behavior.

## Key Observation

Agent position persisted across turns. Because each turn began from the position produced by the previous turn, prior state constrained what could happen next.

## State Note

Energy, age, and memory remained unchanged because update behaviors for those state variable have not yet been implemented.

At this stage, persistent position should not be confused with persistent memory. Position is carried forward as agent state, but agents do not yet retain or use information about previous events.

## Interpretation

EXP-002 demonstrated that the simulation can maintain agent state across turns and apply deterministic behavior subject to an environmental constraint.

This establishes a controlled baseline for later experiments in which memory, environmental traces, reward structures, and other mechanisms can be introduced individually and compared against known deterministic behavior.

## Post-Experiment Revisions

Turn numbering was changed from 0-9 to 1-10 for readability. The simulation still executes ten turns.
