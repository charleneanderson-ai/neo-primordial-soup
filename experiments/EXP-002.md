# EXP-002 Log

Experiment ID: EXP-002
Date: 2026-08-25

## Purpose

Introduce one small deterministic movement rule and observe agent behavior

## Rule Addition

Through a 10-turn simulation, increase each agent's x-coordinate by 1 until it reaches the east edge of the grid without moving beyond the boundary.

## Expected Behavior

Expected Agent_1 to move right until x=9, Agent_2 likewise, and Agent_3 should move from (8,2) to (9,2) on the first turn and then remain there for the remaining turns.

## Observed Behavior

All agents moved sequentially one square to the right with each successive simulation turn until reaching the east boundary, at which point they remained in their position for the remaining turns.

## Result

PASS

## Key Observation

Agents moved east until reaching the grid boundary, then remained in place. Previous state influenced what could happen next.

## State Note

Energy, age, and memory remained unchanged because their update behaviors are not yet implemented.

## Interpretation

Agent position persisted across turns, and prior state constrained subsequent behavior.

## Post-Experiment Revisions

Turn numbering was changed from 0-9 to 1-10.
